২.৩ স্ট্যান্ডার্ড HTTP Status Codes (যেগুলো সবার জানা উচিত)
একটি ওয়েব অ্যাপ্লিকেশন বা RESTful API আর্কিটেকচারে ক্লায়েন্ট (যেমন ওয়েব ব্রাউজার, ফ্রন্টএন্ড Fetch API বা মোবাইল অ্যাপ) এবং ব্যাকএন্ড সার্ভারের মধ্যে প্রতিটি HTTP রিকোয়েস্টের ফলাফল নির্দেশ করতে স্ট্যান্ডার্ড ৩-সংখ্যার HTTP স্ট্যাটাস কোড ব্যবহৃত হয়। নিচে সফটওয়্যার ইঞ্জিনিয়ারিংয়ে সর্বাধিক ব্যবহৃত গুরুত্বপূর্ণ ২০টি কোড, তাদের অফিশিয়াল নাম এবং আমাদের প্রজেক্টে কখন আসে তা বিস্তারিতভাবে তুলে ধরা হলো:
কোড নাম অর্থ ও আমাদের প্রজেক্টে কখন আসে?
100 Continue সার্ভার ক্লায়েন্টের প্রাথমিক অনুরোধের হেডার পেয়েছে এবং বাকি ডেটা/বডি পাঠানো চালিয়ে যেতে নির্দেশ দিচ্ছে।
200 OK রিকোয়েস্ট সফল হয়েছে এবং ডেটা রিটার্ন হয়েছে (যেমন প্রোডাক্ট লিস্ট বা ড্যাশবোর্ড স্ট্যাটাস)।
201 Created নতুন রেকর্ড সফলভাবে তৈরি হয়েছে (যেমন নতুন অর্ডার বা প্রোডাক্ট সফলভাবে ডেটাবেজে সেভ হয়েছে)।
202 Accepted অনুরোধটি সার্ভার গ্রহণ করেছে কিন্তু প্রসেসিং এখনো ব্যাকগ্রাউন্ডে চলছে (যেমন বড় ইনভেন্টরি এক্সপোর্ট বা অ্যাসিনক্রোনাস কাজ)।
204 No Content অ্যাকশন সফলভাবে সম্পন্ন হয়েছে কিন্তু রেসপন্সে ফেরত পাঠানোর মতো কোনো বডি নেই (যেমন কোনো কাস্টমার বা প্রোডাক্ট মুছে ফেলার পর)।
301 Moved Permanently অনুরোধকৃত রিসোর্সটি স্থায়ীভাবে নতুন URL-এ স্থানান্তরিত হয়েছে (ব্রাউজার ও সার্চ ইঞ্জিন সরাসরি নতুন অ্যাড্রেসে রিডাইরেক্ট করে)।
302 Found (Redirect) সাময়িক রিডাইরেকশন (যেমন লগইন ছাড়া প্রোটেক্টেড ড্যাশবোর্ডে প্রবেশের চেষ্টা করলে স্বয়ংক্রিয়ভাবে /login পেজে রিডাইরেক্ট করা)।
304 Not Modified ব্রাউজার ক্যাশে থাকা ডেটা অপরিবর্তিত রয়েছে, ফলে ব্যান্ডউইথ বাঁচাতে সার্ভার থেকে পুনরায় নতুন ডেটা ডাউনলোডের প্রয়োজন নেই।
400 Bad Request ক্লায়েন্টের তথ্যে কোনো যুক্তিগত ভুল (যেমন ইতিমধ্যে ব্যবহৃত SKU দিয়ে প্রোডাক্ট অ্যাড করার চেষ্টা)।
401 Unauthorized ব্যবহারকারী লগইন করেননি বা কুকিতে থাকা JWT টোকেন মেয়াদোত্তীর্ণ বা অবৈধ।
403 Forbidden ব্যবহারকারী লগইন অবস্থায় আছেন কিন্তু উক্ত রিসোর্স অ্যাক্সেস বা মডিফাই করার অনুমতি বা রোল তার নেই।
404 Not Found যে আইডি চাওয়া হয়েছে তা ডেটাবেজে নেই (যেমন এমন কোনো অর্ডার আইডি যা বিদ্যমান নেই)।
405 Method Not Allowed অনুরোধকৃত রুটে অননুমোদিত HTTP মেথড পাঠানো হয়েছে (যেমন যে এপিআই শুধু POST গ্রহণ করে সেখানে GET কল করা)।
408 Request Timeout সার্ভার নির্ধারিত সময়ের মধ্যে ক্লায়েন্টের কাছ থেকে সম্পূর্ণ অনুরোধ পায়নি (ধীরগতির ইন্টারনেট বা সংযোগ বিচ্ছিন্ন)।
409 Conflict ডেটাবেসের বর্তমান ডেটার সাথে সংঘর্ষ (যেমন ইতিমধ্যে নিবন্ধিত ইউনিক ইমেইল বা ফোন নম্বর দিয়ে দ্বিতীয়বার একাউন্ট খোলার চেষ্টা)।
422 Unprocessable Entity Pydantic ডেটা ভ্যালিডেশন ব্যর্থ (যেমন দামের ঘরে সংখ্যার বদলে লেখা বা লিমিট অতিক্রম)।
429 Too Many Requests নির্দিষ্ট সময়ের মধ্যে অনুমোদিত সীমার অতিরিক্ত রিকোয়েস্ট পাঠানো হয়েছে (Rate Limiting বা ব্রুট-ফোর্স অ্যাটাক রোধে)।
500 Internal Server Error সার্ভারের অভ্যন্তরীণ ক্র্যাশ বা ডেটাবেস কানেকশন ফেইলিয়র।
502 Bad Gateway রিভার্স প্রক্সি বা গেটওয়ে (যেমন Nginx) মূল ব্যাকএন্ড সার্ভার (FastAPI/Uvicorn) থেকে অকার্যকর বা ব্যর্থ রেসপন্স পেয়েছে।
503 Service Unavailable সার্ভারে অতিরিক্ত ট্রাফিক চাপ বা সাময়িক সিস্টেম মেইনটেন্যান্স চলার কারণে সেবা সাময়িকভাবে বন্ধ থাকা।
HTTP Status Code ৫টি প্রধান ক্যাটাগরি সারসংক্ষেপ:
1xx: Informational
2xx: Success
3xx: Redirection
4xx: Client Error
5xx: Server Error
